# 🎓 大学文字模拟器 · UniLifeSim

一款纯前端、零依赖的文字大学生活模拟游戏：从拖着行李箱走进校门开始，走过大一到大四 8 个学期，在**学业、社交、体质、心态、金钱、恋爱**之间做选择，最后走向属于你的毕业结局。

- **运行方式**：直接用浏览器打开 `index.html`（双击即可，无需安装、无需联网、无需服务器）。手机 / 电脑均可游玩，界面自适应。
- **引擎架构**：`js/data/*.js`（内容数据） + `js/engine.js`（纯逻辑引擎，无 DOM，可被 Node 加载） + `js/ui.js`（界面渲染）。
- **测试**：`node tools/validate.js` 校验数据完整性；`node tools/sim.js` 跑无头全自动局，检查崩溃/死锁/结局分布。

## 玩法速览

- 每个「学期」有若干周（8 个学期共约 100 周）；每周从可用行动中选一个（自习、社团、兼职、运动、休息、打游戏、社交、约会、追TA、方向类行动…），随后可能触发随机事件。
- **四维属性**（0-100）：学业 / 社交 / 体质 / 心态；另有金钱、恋爱值、绩点(GPA)、挂科数、奖学金；每周还有固定的生活开销，家境不同压力不同。
- 每学期期末自动结算成绩 → 绩点与挂科；挂科过多会触发补考、学业预警甚至劝退；每学年评奖学金；心态/体质过低会被辅导员/校医院拉回。
- 每学期有 **主线节拍**（军训、百团大战、偶遇心动对象、表白、方向抉择…）在固定周自动上演，做出关键抉择。
- **大三上末的「人生岔路口」**决定大三大四方向：考研 / 考公 / 就业 / 创业 / 躺平 —— 不同方向解锁不同行动、事件与结局。
- 高绩点玩家在大四上会收到「推免（保研）」资格邀请。
- 恋爱线从大二一次偶遇开始：追不追、表白不表白，都看你自己。
- 支持自动存档（localStorage），随时可关掉浏览器下次继续；结局解锁会记录进「结局图鉴」。

## 数据内容（简体中文，轻松幽默为主、偶尔走心）

## 开发自检

```bash
node tools/validate.js          # 数据完整性（id 唯一、字段合法、节拍全覆盖、flag 白名单）
node tools/sim.js 1000          # 无头模拟 1000 局（6 种玩法策略混跑），检查崩溃/死锁/结局分布
```

实测（1000 局模拟）：**零崩溃、零死锁**，18/20 结局自然触达，E20/E05 需特定玩法/隐藏路线。平均绩点 2.3、平均结余 1.1 万元，属性全程保持在 0–100 健康区间。

## 说明

- 存档保存在浏览器 `localStorage`（每周自动保存 + 手动保存），更换浏览器/清除数据会丢失。
- 本游戏为虚构叙事，出现的校园人物、事件、结局均为创作内容，请理性游戏、健康生活。
