# 兵兵快跑 · 神了！寿星版

一个给兵兵的手机生日跑酷小游戏。

## 开玩

手机竖屏优先，电脑也支持。直接打开本目录的 index.html 即可离线运行，整个游戏只有一个文件，不依赖 CDN、远程字体、图片或音频。

- 左右滑换道，上滑跳跃，下滑滑铲；也可点底部按钮。
- 点闪电释放 7 秒忍者跑，无敌并吸取道具。
- 金币与汉堡充能，炸鸡加速，蛋糕提供 5 秒无敌。
- 生日闯关为 120 秒、三个主题；另有无限挑战和本地最高分。
- 电脑支持方向键 / WASD、空格跳跃、E 大招、P / Esc 暂停。
- 切换到其他应用会自动暂停，返回后手动继续。
- 首页和游戏右上角可切换声音。没有本地中文声音时跳过语音，保留合成音乐与音效。

生日结尾：**恭喜你又老了一岁！**

没有登录、广告、付费或分析追踪；分数和静音选项只存在当前浏览器。
