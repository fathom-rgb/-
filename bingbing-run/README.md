# 兵兵快跑 · 神了！寿星版

给兵兵的手机生日跑酷小游戏。单文件，无外部字体、图片、脚本或音频依赖。

## 本次更新

- 生日模式缩短为60秒，每20秒切换一个主题，60秒抵达生日现场。
- 首页可选：豆包——兵兵（女）；奶龙——兵兵（男）。
- 角色预览即时切换，当前浏览器记住选择，重开时保留。
- 无限模式继续挑战，不受60秒生日计时限制。

## 玩法

手机左右滑换道，上滑跳跃，下滑滑铲；也能点底部按钮。金币和汉堡为大招充能，炸鸡加速，蛋糕无敌。闪电按钮释放7秒忍者跑：无敌加全路吸道具。

电脑：方向键或WASD，空格跳跃，E大招，P或Esc暂停。切换应用后自动暂停。

结尾：**恭喜你又老了一岁！**

直接下载本目录index.html即可离线运行。声音在设备本地合成，语音只使用设备已有的本地中文声音；无可用声音时跳过语音。没有登录、广告、付费和追踪，分数与选择只保存在浏览器。
